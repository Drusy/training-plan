# Política de privacidad

## Acerca de

{{ site.app_name }} es una app de iOS que ayuda a los atletas a gestionar sus próximas competiciones y a generar planes de entrenamiento personalizados mediante IA. Es compatible con running, ciclismo, natación y triatlón.

## Datos que utilizamos

{{ site.app_name }} puede acceder a los siguientes datos para ofrecer funciones principales:

- Datos de perfil del atleta (deporte, nivel de experiencia, peso opcional)
- Datos de competiciones (fechas, distancias, objetivos)
- Datos de plan de entrenamiento y sesiones (programa, estado de completado)
- Conexión opcional con Strava (solo si el usuario la activa)
- Notificaciones locales opcionales (solo si el usuario lo permite)

## Cómo se almacenan los datos

Todos los datos de competiciones, planes y perfil se almacenan localmente en tu dispositivo.  
No gestionamos servidores ni recopilamos tus datos personales.

Cuando eliges Claude (Anthropic) o GPT-4o (OpenAI) para generar un plan, tu perfil y objetivos se envían a la API del proveedor correspondiente. Esto está cubierto por sus respectivas políticas de privacidad:

- [Política de privacidad de Anthropic](https://www.anthropic.com/privacy)
- [Política de privacidad de OpenAI](https://openai.com/privacy)

No vendemos datos personales.

## Permisos

Según las funciones activadas, la app puede solicitar:

- Permiso de notificaciones (recordatorios diarios de entrenamiento y alertas de sesiones)
- Acceso a Internet (para generación de planes con IA y sincronización opcional con Strava)

Los recursos de marcas de terceros (p. ej., botón de Strava) se usan según sus guías de marca.
